# การปรับ \clubpenalty / \widowpenalty ใน reading mode

**บริบท:** footnote ถูกปักไว้ที่ท้ายหน้าจริงเสมอ (footmisc `bottom`) เพื่อให้เส้น
footnote ตรงกันทุกหน้าคู่ — เป็นความต้องการหลักที่ต้องคงไว้ (ดู README หัวข้อ
Footnotes) ผลคือ **ช่องว่างระหว่างท้ายเนื้อความกับเส้น footnote แปรผันตาม
ความสูงที่เหลือของหน้านั้น** โดยตรง ถ้าหน้าไหนจบสั้นกว่าปกติ ช่องว่างจะกว้างขึ้น
ตามไปด้วย

ก่อนหน้านี้เคย “แก้” ด้วยการ patch `\vfill` ของ footmisc ให้เป็น `\vskip\z@`
(บังคับช่องว่างคงที่) แต่ทำให้เส้น footnote ของหน้าคู่ตรงข้ามเยื้องกัน — ผู้ใช้ตัดสินใจ
**ย้อนกลับ** และให้ตำแหน่ง footnote เท่ากันทุกหน้าเป็นเงื่อนไขสำคัญกว่า

## สาเหตุที่หน้าจบสั้น

`reading` mode ให้ TeX เลือกจุดตัดหน้าเอง (`sync` mode บังคับจุดตัดผ่าน
`\csromanpage` เสมอ ไม่เกี่ยวกับ penalty นี้เลย) ค่าที่ตั้งไว้เดิม
`\clubpenalty=10000` / `\widowpenalty=10000` คือ “ห้ามเด็ดขาด” — TeX จะไม่ยอม
ตัดหน้าใด ๆ ที่ทิ้งบรรทัดเดี่ยวไว้ (club/widow line) แม้ทางเลือกเดียวที่เหลือคือ
ตัดหน้าให้สั้นกว่าที่ควรราว ๆ 1–2 บรรทัด (~14–27pt) ร่วมกับ `\raggedbottom`
ผลต่างความสูงนี้จึงไปโผล่เป็นช่องว่างเนื้อความ→เส้น footnote ที่ใหญ่ผิดปกติ
บนหน้านั้น ทั้งที่ไม่มีเหตุผลเชิงเนื้อหาให้ต่างจากหน้าข้างเคียงเลย

## วิธีวัด

- `scripts/scratch/_measure_page_shortfall.py` — อ่าน PDF, หาเส้น footnote
  (จาก `page.get_drawings()`) และบรรทัดเนื้อความสุดท้ายเหนือเส้นนั้น (กรอง
  header/folio mark ด้วยช่วง x/y) แล้วคำนวณช่องว่าง (gap) ต่อหน้า
- `scripts/scratch/_sweep_penalty.py` — วน set `\clubpenalty`/`\widowpenalty`
  (เฉพาะ branch `\ifdefined\csromanusereadinggeometry` ใน `preamble.tex`)
  หลายค่า, build reading mode ใหม่ทุกครั้ง, สรุปสถิติของ gap เฉพาะหน้าที่มี
  footnote (ตัดหน้าที่ gap > 100pt ทิ้งเพราะเป็นหน้าใกล้หัวข้อ/ท้ายบท ซึ่งจบสั้น
  โดยธรรมชาติ ไม่เกี่ยวกับ penalty นี้)

ทั้งสองไฟล์เป็นสคริปต์ทดลอง (`scripts/scratch/`) ไม่ใช่ pipeline — เก็บไว้เผื่อ
ต้อง re-tune ในอนาคต (เช่น มีเล่มใหม่ที่ page-fill ต่างมาก)

## ทำไมเลือก 2000 (ทดลอง — ย้อนกลับแล้ว)

Sweep ด้านบนใช้ทดลองผ่อน penalty ใน reading mode (10000 → 2000) เพื่อลด gap
บางหน้า หลังพบว่าปัญหาหลัก (เช่น 01Vin01 reading หน้า 20) มาจาก footnote packing
credit ไม่ใช่ club/widow — **ย้อนกลับ `\clubpenalty`/`\widowpenalty` = 10000**
ทั้ง sync และ reading (`preamble.tex`) เพื่อคงหลัก “ห้ามบรรทัดเดียวโดดเดี่ยว”
โดยไม่เก็บ workaround ที่สองไว้คู่กับ packing credit

## สิ่งที่ยังไม่แก้ / ที่แก้เพิ่มแล้ว

Gap ที่เหลือจาก club/widow (mean ~28–29pt หลังผ่อน penalty) เป็นคนละเรื่องกับ
**ช่องว่างใหญ่บนหน้าที่มี footnote หลายอันแพ็กเหลือแถวเดียว** — กรณีหลังเกิดจาก
TeX จองความสูงแบบเรียงซ้อนตอนตัดหน้า แต่ `\@makecol` แพ็ก 2–3 โน้ตต่อแถว
ทำให้มีที่เหลือไปโผล่เป็นช่องว่างเนื้อความ→เส้น (ตัวอย่าง 01Vin01 reading หน้า 20
เดิม gap ≈ 55pt ทั้งที่ข้อ 32 ต่อได้อีก ~2 บรรทัดโดยไม่กลายเป็น orphan)

แก้ที่ `shared/style/footnotes.tex` (`\csromanfn@footnotetext`): ให้ short/tiny
credit ความสูงตอน `\insert` (~½ / ~⅓) ให้ตรงกับที่แพ็กเกอร์จะทำ — หลังแก้
หน้า 20 gap ≈ 16.5pt และเนื้อความข้อ 32 ไหลต่อในพื้นที่นั้นตามที่ควร
Regression: `test_packed_tiny_notes_do_not_leave_two_line_gap`

ถ้าต้องการ gap คงที่ทุกหน้าจริง ๆ (รวมหน้าไม่มี footnote แพ็ก) ต้องแลกกับ
ตำแหน่ง footnote ที่ไม่ตรงกันข้ามหน้าคู่ (ดูการทดลอง patch `\vfill` ที่ถูก
ย้อนกลับไปแล้วในหัวข้อ Footnotes ของ README)
