## 1. การปริวรรตอักษรโรมันเป็นไทยสำหรับคำควบกล้ำ

### 1.1 ทำความรู้จักพยัญชนะและสระในภาษาบาลี

ก่อนจะพูดถึงคำควบกล้ำ ต้องรู้จักหน่วยอักษรพื้นฐานของบาลีก่อน  
ตารางด้านล่างใช้คู่ **โรมัน (IAST)** ↔ **ไทย** ตามแบบที่ใช้อ่านพระไตรปิฎก

#### พยัญชนะ (byañjana)

พยัญชนะบาลีจัดเป็นวรรคตามฐานเสียง (จากคอ → ริมฝีปาก) แล้วตามด้วยอวรรค


| วรรค                | กัก | ส่งลม | ก้อง | ก้อง+ส่งลม | นาสิก |
| ------------------- | --- | ----- | ---- | ---------- | ----- |
| กณฺฐช (คอ)          | k ก | kh ข  | g ค  | gh ฆ       | ṅ ง   |
| ตาลุช (เพดาน)       | c จ | ch ฉ  | j ช  | jh ฌ       | ñ ญ   |
| มุทฺธช (ปุ่มเหงือก) | ṭ ฏ | ṭh ฐ  | ḍ ฑ  | ḍh ฒ       | ṇ ณ   |
| ทันตช (ฟัน)         | t ต | th ถ  | d ท  | dh ธ       | n น   |
| โอฏฺฐช (ริมฝีปาก)   | p ป | ph ผ  | b พ  | bh ภ       | m ม   |


อวรรค (ไม่เข้าวรรคห้าข้างบน):


| โรมัน | ไทย | หมายเหตุสั้น ๆ                             |
| ----- | --- | ------------------------------------------ |
| y     | ย   | กึ่งสระ                                    |
| r     | ร   |                                            |
| l     | ล   |                                            |
| ḷ     | ฬ   | เสียง ล มุทฺธช (มีจุดใต้ในโรมัน)           |
| v     | ว   |                                            |
| s     | ส   | ในบาลีมี s เดียว (ไม่มี ś / ṣ เป็นตัวหลัก) |
| h     | ห   |                                            |


รวมพยัญชนะหลักของบาลี = **๓๓ ตัว** (๒๕ ในวรรค + ๘ อวรรค รวม ṃ เป็นเครื่องหมายแยกด้านล่างในทางปฏิบัติของการปริวรรต)

จุดที่ต้องจำตอนอ่านโรมัน:

- ตัวที่มี **h ตามหลัง** (`kh`, `gh`, `ṭh`, …) คือพยัญชนะตัวเดียว ไม่ใช่สองตัวติดกัน
- ตัวที่มี **จุดใต้** (`ṭ ṭh ḍ ḍh ṇ ḷ`) คือวรรคมุทฺธช / ฬ — คนละตัวกับ `t th d dh n l`
- `ṅ ñ ṇ n m` คนละตัวกัน แม้ไทยจะดูใกล้เคียงเมื่ออ่านเร็ว

#### สระ (sara)

สระบาลีหลักมี **๘ เสียง**:


| โรมัน | ไทย (อิสระ) | ไทย (เมื่อติดพยัญชนะ)            | สั้น/ยาว |
| ----- | ----------- | -------------------------------- | -------- |
| a     | อ / อะ      | *(สระแฝง — ไม่เขียนเครื่องหมาย)* | สั้น     |
| ā     | อา          | า                                | ยาว      |
| i     | อิ          | ิ                                | สั้น     |
| ī     | อี          | ี                                | ยาว      |
| u     | อุ          | ุ                                | สั้น     |
| ū     | อู          | ู                                | ยาว      |
| e     | เอ          | เ…                               | ยาว      |
| o     | โอ          | โ…                               | ยาว      |


หลักสั้น ๆ:

1. พยัญชนะตัวเดียวโดยไม่มีสระอื่นกำกับ = มีสระ **a** แฝงอยู่แล้ว
  ตัวอย่าง: `ka` → ก, `kha` → ข, `ga` → ค
2. สระอื่นเขียนด้วยรูปสระไทยตามตาราง
  ตัวอย่าง: `kā` → กา, `ki` → กิ, `ku` → กุ, `ke` → เก, `ko` → โก
3. สระที่ต้นคำ (ไม่มีพยัญชนะนำ) ใช้รูปอิสระ
  ตัวอย่าง: `assa` → อสฺส, `eva` → เอว, `iti` → อิติ

#### เครื่องหมายที่ต้องรู้จักคู่กับพยัญชนะ–สระ


| ชื่อ                   | โรมัน                  | ไทย | ความหมายสั้น ๆ                                              |
| ---------------------- | ---------------------- | --- | ----------------------------------------------------------- |
| นิคหิต (niggahīta)     | ṃ (หรือ ṁ)             | ํ   | เสียงนาสิกท้ายพยางค์ เช่น `aṃ` → อํ, `saṃ` → สํ             |
| พินทุ / วิราม (virāma) | *(ไม่มีตัวอักษรโรมัน)* | ฺ   | ฆ่าสระ a แฝงของพยัญชนะ — ใช้เมื่อพยัญชนะซ้อนกัน (คำควบกล้ำ) |


ตัวอย่างแยกหน่วย (ยังไม่แยกประเภทซ้อน/กล้ำ):


| โรมัน    | แยกเป็น            | ไทย   |
| -------- | ------------------ | ----- |
| `buddha` | b + u · d + dh + a | พุทฺธ |
| `dhamma` | dh + a · m + m + a | ธมฺม  |
| `saṅgha` | s + a · ṅ + gh + a | สงฺฆ  |


### 1.2 สมมติฐานเรื่องคำกล้ำ

จากตัวอย่างตั้งต้น:


| โรมัน   | คลัสเตอร์ | ตัวที่ ๑         | ตัวที่ ๒      | สระร่วม |
| ------- | --------- | ---------------- | ------------- | ------- |
| `pañho` | ñh        | ñ (นาสิก จ-วรรค) | **h** (อวรรค) | o       |
| `tumhe` | mh        | m (นาสิก ป-วรรค) | **h** (อวรรค) | e       |
| `dve`   | dv        | d (ท-วรรค)       | **v** (อวรรค) | e       |


**สมมติฐานที่ทดสอบ**

1. การกล้ำเกิดเมื่อพยัญชนะ **๒ ตัวใช้สระร่วมกัน** (ไม่มีสระคั่นกลาง; สระอยู่หลังตัวที่ ๒)
2. **พยัญชนะตัวที่ ๒ เป็นอวรรค**

### 1.3 หลักจากแหล่งภายนอก

ในตำราบาลีไทย พยัญชนะที่อยู่ติดกันโดยไม่มีสระคั่นเรียกรวมว่า **พยัญชนะสังโยค** แต่แยกเป็น ๒ แบบ:


| แบบ                      | ลักษณะออกเสียง                                               | ตัวหลังมักเป็น                          |
| ------------------------ | ------------------------------------------------------------ | --------------------------------------- |
| **ตัวสะกด / ตัวซ้อน**    | ตัวหน้าเป็นตัวสะกดของสระข้างหน้า; ตัวหลังมีสระของตน          | พยัญชนะ**วรรค** (เช่น kk, tth, ndh, mm) |
| **ตัวกล้ำ / ตัวควบกล้ำ** | พยัญชนะออกเสียง**ผสม**กัน อาศัยสระที่อยู่หลังตัวท้ายของกลุ่ม | พยัญชนะ**อวรรค** โดยเฉพาะ **ย ร ล ว ห** |


แหล่งอ้างอิงหลัก:

- [ภาษาบาลี : สังเกตการเขียนอักษร](http://palidhammabhasa.blogspot.com/2016/06/blog-post_39.html) — ย ร ล ว ห เมื่ออยู่หลังพยัญชนะอื่น = **ตัวกล้ำ**
- [Pali Blog: พยัญชนะสังโยค](http://primaypaligrmmar.blogspot.com/2013/10/blog-post_15.html) — แยกตัวสะกด กับ ตัวควบกล้ำ; สระอาศัยอยู่หลังตัวที่ ๒ หรือ ๓
- [บาลีเสริม: การสะกดตัว](http://taninkha.blogspot.com/2015/08/blog-post_25.html) — พินทุในอักษรกล้ำ; ย ร ล ว อยู่หลังพยัญชนะอื่น = ออกเสียงผสม
- [Pariyatti: Conjunct Consonants](https://learning.pariyatti.org/mod/page/view.php?id=2230) — miscellaneous (y r l v h s) รวมกับวรรคอื่นได้ เช่น `tatra`, `brāhmaṇa`, `kvaci`, `taṇhā`

กฎย่อยของตัวกล้ำ (จากตำราไทยข้างต้น):


| ตัวกล้ำ | กล้ำกับพยัญชนะวรรคได้ประมาณ | ตัวอย่างโรมัน                                        |
| ------- | --------------------------- | ---------------------------------------------------- |
| **y**   | ที่ ๑–๕                     | `sakya`, `ākhyāta`, `ārogya`, `adhyattha`, `nyāsa`   |
| **r**   | ที่ ๑ และ ที่ ๓             | `tatra`, `brūti`                                     |
| **l**   | ที่ ๑                       | `klesa` / `kilesa`, `plava`                          |
| **v**   | ที่ ๑–๕                     | `kvaci`, `khvāhaṃ`, `dve`, `sādhvalaṅkati`, `anveti` |
| **h**   | ที่ ๕ (นาสิก)               | `pañhā` / `pañho`, `tumhe`, `taṇhā`, `jivhā`         |


ข้อจำกัดสำคัญ: อวรรคมี ๘ ตัว (ย ร ล ฬ ว ส ห ํ) แต่ที่ทำหน้าที่ **ตัวกล้ำ** ตามตำราไทยคือ **ย ร ล ว ห** เป็นหลัก  
`s` / `ḷ` / `ṃ` ไม่เข้าสมมติฐานนี้ในบทบาทเดียวกัน (เช่น `ssa` เป็นตัวสะกด ไม่ใช่กล้ำ)

### 1.4 คลังตัวอย่างคำที่ออกเสียงกล้ำ (อักษรโรมัน)

จัดตามตัวกล้ำตัวที่ ๒ (หรือตัวท้ายของกลุ่มกล้ำ)

#### กล้ำด้วย **y**


| โรมัน       | กลุ่ม | หมายเหตุสั้น ๆ      |
| ----------- | ----- | ------------------- |
| `sakya`     | ky    | ก + y               |
| `ākhyāta`   | khy   | ข + y               |
| `ārogya`    | gy    | ค + y               |
| `adhyattha` | dhy   | ธ + y               |
| `nyāsa`     | ny    | น + y               |
| `byādhi`    | by    | พ/บ + y             |
| `vyaggha`   | vy    | ว + y (ต้นคำ)       |
| `kalyāṇa`   | ly    | ล + y (อวรรค+อวรรค) |
| `ālasya`    | sy    | ส + y               |


#### กล้ำด้วย **r**


| โรมัน      | กลุ่ม   | หมายเหตุสั้น ๆ            |
| ---------- | ------- | ------------------------- |
| `tatra`    | tr      | ต + r                     |
| `atrajaṃ`  | tr      | ต + r                     |
| `brūti`    | br      | พ + r                     |
| `brāhmaṇa` | br … hm | มีทั้ง br และ hm          |
| `indriya`  | ndr     | สามตัว: นฺทฺร (สะกด+กล้ำ) |


#### กล้ำด้วย **l**


| โรมัน      | กลุ่ม | หมายเหตุสั้น ๆ                 |
| ---------- | ----- | ------------------------------ |
| `klesa`    | kl    | มักแทรกสระเป็น `kilesa` ในบาลี |
| `plava`    | pl    | ป + l                          |
| `pilavati` | —     | รูปแยกสระจาก pl                |


#### กล้ำด้วย **v**


| โรมัน                            | กลุ่ม | หมายเหตุสั้น ๆ  |
| -------------------------------- | ----- | --------------- |
| `dve` / `dvi`                    | dv    | ตัวอย่างตั้งต้น |
| `kvaci`                          | kv    | ก + v           |
| `khvāhaṃ`                        | khv   | ข + v           |
| `anveti`                         | nv    | น + v           |
| `svākkhāta`                      | sv    | ส + v           |
| `juhvati`                        | hv    | ห + v           |
| `gantvā`                         | ntv   | สามตัว: นฺตฺว   |
| `cakkhu` + `vā` → `cakkhvāpātha` | kkhv  | สะกด+กล้ำ       |


#### กล้ำด้วย **h**


| โรมัน                 | กลุ่ม   | หมายเหตุสั้น ๆ                        |
| --------------------- | ------- | ------------------------------------- |
| `pañho` / `pañhā`     | ñh      | ตัวอย่างตั้งต้น                       |
| `tumhe`               | mh      | ตัวอย่างตั้งต้น                       |
| `taṇhā`               | ṇh      | ณ + h                                 |
| `jivhā`               | vh      | ว + h                                 |
| `gayhati` / `pasayha` | yh      | ย + h                                 |
| `āruyha` / `ārūḷha`   | yh / ḷh | ย/ฬ + h                               |
| `brahma` / `brāhmaṇa` | hm      | ห เป็นตัวหน้า กล้ำม (ข้อยกเว้นทิศทาง) |

| โรมัน         | กลุ่ม | โครง          |

### 1.5 คำที่เป็นพยัญชนะซ้อน (ไม่ใช่กล้ำ) — ใช้เทียบสมมติฐาน

ตัวที่ ๒ **ไม่ใช่** อวรรคกล้ำ → เป็นตัวสะกด/ซ้อน แม้เขียนด้วยพินทุเหมือนกัน:


| โรมัน    | กลุ่ม | ตัวที่ ๒                                  |
| -------- | ----- | ----------------------------------------- |
| `buddha` | ddh   | dh (วรรค)                                 |
| `dhamma` | mm    | m (วรรค)                                  |
| `sakko`  | kk    | k (วรรค)                                  |
| `atthi`  | tth   | th (วรรค)                                 |
| `saṅgha` | ṅgh   | gh (วรรค)                                 |
| `assa`   | ss    | s (อวรรค แต่ทำหน้าที่**สะกด** ไม่ใช่กล้ำ) |


### 1.6 ข้อสรุปต่อสมมติฐาน


| ข้อ                          | ผล                            | รายละเอียด                                                                                 |
| ---------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------ |
| พยัญชนะ ๒+ ตัวใช้สระร่วมกัน  | **สนับสนุน**                  | ตัวกล้ำออกเสียงผสม อาศัยสระหลังกลุ่ม; ตัวที่ไม่ใช่ตัวท้ายมีพินทุ (ฺ)                       |
| ตัวท้ายของกลุ่มกล้ำเป็นอวรรค | **สนับสนุน** (จำกัด)          | ตัวกล้ำหลัก = **ย ร ล ว ห** (ไม่ใช่อวรรคทั้ง ๘ — `s` ใน `ssa` เป็นสะกด)                    |
| แยกจากพยัญชนะซ้อน (ตัวสะกด)  | **จำเป็น**                    | `buddha` / `dhamma` / `assa` เป็นสังโยคแบบสะกด ไม่ใช่กล้ำ                                  |
| กลุ่ม ๓ ตัว = สะกด+กล้ำ      | **สนับสนุน**                  | ตัวท้ายยังเป็น ย/ร/ว เช่น `indriya` อินฺทฺริย, `gantvā` คนฺตฺวา                            |
| ข้อยกเว้นทิศทาง              | **มี**                        | เช่น `hm` ใน `brahma` (ห นำ ม ตาม)                                                         |
| สระหน้ากับคำกล้ำ             | **กฎเพิ่มจากตารางที่ถูกต้อง** | เ / โ (และสระหน้าอื่น) ต้องอยู่**หน้าพยัญชนะทั้งกลุ่มที่กล้ำ** ไม่ใช่หน้าตัวท้ายอย่างเดียว |


**สรุปสั้น:** “กล้ำ” = พยัญชนะติดกันที่ออกเสียงผสม โดยตัวท้ายเป็น ย/ร/ล/ว/ห และมีสระร่วมหลังกลุ่ม  
การเขียนไทย: พินทุที่ตัวที่ไม่ใช่ตัวท้าย + ถ้าสระเป็นสระหน้า → วางสระนั้นหน้าทั้งกลุ่ม

### 1.7 ตารางจับคู่โรมัน ↔ ไทย (คำกล้ำ)

### 1.8 สรุปกฎ (ลงโค้ดใน `pali_script` แล้ว)

#### ก. นิยามที่ใช้แยกประเภท

1. **พยัญชนะสังโยค** = พยัญชนะ ≥๒ ตัวติดกัน ไม่มีสระคั่น (ในโรมัน)
2. **ตัวสะกด / ซ้อน** = สังโยคที่ตัวท้าย**ไม่ใช่**ตัวกล้ำ (ย ร ล ว ห) — เช่น `ddh`, `mm`, `kk`, `ss`
3. **ตัวกล้ำ** = สังโยคที่ตัวท้ายเป็น **y r l v h** และพยัญชนะในกลุ่ม**ใช้สระร่วมกัน** (สระอยู่หลังกลุ่มในโรมัน)
4. **สะกด+กล้ำ** = มีทั้งตัวสะกดและตัวกล้ำในกลุ่มเดียวกัน (มัก ๓ ตัว) ตัวท้ายเป็น y/r/v — เช่น `ndr`, `ntv`, `ṅkhy`

#### ข. กฎปริวรรตโรมัน → ไทย

**B1–B3** แมปอักษร / พินทุ / สระไม่ใช่สระหน้า — ตามเดิม

**B4. สระหน้า** (`e`→เ, `o`→โ) **กับคำกล้ำ**  
(บาลีไม่มี `ai`/ไ เป็นสระหลัก)

- วางสระหน้า**หน้าพยัญชนะฐานของคู่กล้ำ** (ตัวก่อน y/r/l/v/h/ḷ)
- ตัวสะกดที่มาก่อนคู่กล้ำให้อยู่**หน้า**สระนั้นต่อ  
  ตัวอย่าง: `dve` → **เทฺว**, `aññindreyena` → อญฺญินฺ**เทฺร**เยน, `asaṅkhyeyyo` → อสงฺ**เขฺย**ยฺโย
- ไม่ย้ายทั้ง virama run แบบเหมารวม (ผิดรูปเช่น เนฺทฺร / อสเงฺขฺย)
- ข้าม geminate ยฺย / ลฺล (เช่น ท้าย `asaṅkhyeyyo` คง **ยฺโย**)

**B5.** สระหน้า + พยัญชนะตัวเดียว — คงเดิม (`buddho` → พุทฺโธ)

**B6.** ตัวสะกด / ซ้อน ที่ไม่ใช่กล้ำ — คงเดิม (`saṅgho` → สงฺโฆ)
