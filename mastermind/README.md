# Mastermind

## วัตถุประสงค์

เอกสารในส่วนนี้กำหนดนโยบาย ยุทธศาสตร์ แผนงาน และการกำกับโครงการของหอพระไตรปิฎก (Tipiṭaka Hall · SACRED) และระบบดิจิทัล `hall.tptk.org`

ขอบเขตจำกัดอยู่ที่ระดับนโยบายและการวางแผน ไม่รวมคู่มือทางเทคนิค หรือรายงานสถานะการพัฒนาระบบ

## รายการเอกสาร

| เอกสาร | สาระ |
|--------|------|
| [policy.md](./policy.md) | นโยบาย พันธกิจ เป้าหมาย ขอบเขต บทบาทของปัญญาประดิษฐ์ และหลักการตัดสินใจ |
| [strategy.md](./strategy.md) | ยุทธศาสตร์ระบบความรู้กลาง และลำดับการพัฒนา |
| [roadmap.md](./roadmap.md) | แผนงานตามระยะ และเกณฑ์ความสำเร็จ |

## ความสัมพันธ์กับเอกสารอื่น

สถานะทางเทคนิคและการดำเนินงานรายละเอียด อยู่ใน `docs/` โดยเฉพาะ `docs/phase1_complete.md`

## หลักการจัดทำเอกสาร

๑. ใช้ภาษาที่เป็นทางการ ชัดเจน และกระชับ  
๒. สรุปเป็นประเด็นนโยบายหรือแผนงาน ไม่ยกแหล่งข้อมูลหรือช่องทางสื่อสารขึ้นเป็นหัวข้อ  
๓. จำกัดเนื้อหาให้อยู่ในระดับนโยบายและแผนงาน ไม่ระบุขั้นตอนการพัฒนาหรือรายละเอียดเชิงเทคนิค  
๔. แก้ไขเมื่อมีการเปลี่ยนแปลงทิศทางขององค์กรหรือโครงการ ไม่แก้ไขตามการเปลี่ยนแปลงของรหัสโปรแกรมทุกรอบ
